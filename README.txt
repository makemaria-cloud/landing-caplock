DAYA Group — лендинг CUP-LOCK, версия 13

Как открыть:
1. Распакуйте архив полностью.
2. Откройте index.html в современном браузере.

В комплекте: HTML, стили, JavaScript, фотографии и схемы.
Фотографии, карусели, раскрытие отзывов и проверка полей работают локально.
Форма демонстрационная: данные и файлы не отправляются.
Телефон, почта и MAX доступны по ссылкам; для них требуется соответствующее приложение или интернет.

Для размещения на хостинге загрузите содержимое папки DAYA_CUP-LOCK на сервер.
