# Лендинг CUP-LOCK DAYA

Статический лендинг DAYA Group для аренды объемной опалубки CUP-LOCK.

## Исходная версия

Первая версия репозитория получена из `DAYA_CUP-LOCK_v13.zip`, предоставленного
владельцем. Все 17 исходных файлов, включая фотографии, стили, JavaScript и
`README.txt`, перенесены без изменения содержимого.

SHA-256 исходного архива:

```text
59701e629397398b33bbac9e1d52f91b375e645f85e15c1017a6cacf66263a74
```

Архив остается у владельца и не дублируется в Git. Правила и этот документ
добавлены отдельно от исходных материалов лендинга.

## Просмотр

Открыть [index.html](index.html) в современном браузере. Отдельный сервер,
установка зависимостей, Docker и база данных для этой версии не нужны.

В составе страницы есть фотографии, схемы, карусели, отзывы, увеличение
изображений и проверка полей формы.

**Форма демонстрационная: данные и файлы не отправляются.** Для рабочего
приема заявок нужен отдельный согласованный обработчик. Ссылки на телефон,
почту и MAX присутствуют в исходной странице.

## Работа с проектом

Перед обновлением прочитать:

- [AGENTS.md](AGENTS.md): обязательные инструкции всем исполнителям.
- [CODING_RULES.md](CODING_RULES.md): правила реализации и проверок.
- [CONSULTANT_RULES.md](CONSULTANT_RULES.md): правила постановки задач и приемки.

После каждого завершенного обновления обязателен коммит с сообщением на
русском языке и push в текущую рабочую ветку без отдельного напоминания.
В отчете указывать ссылку на отправленный коммит и результаты проверок.

Основная ветка: `main`. Репозиторий содержит только этот лендинг и его
документацию. Базы данных, выгрузки, переписки, пароли и ключи не загружать.

## Размещение

Для статического хостинга используются `index.html`, `style.css`, `app.js`,
`form-utils.js` и папка `assets/`. Сам push в GitHub не публикует сайт и
не подключает обработчик формы. Автоматическая публикация не настроена.
